# Urooj Ahmed — Portfolio

A responsive static portfolio site. No build tools or package installation are required.

## Preview

Open `index.html` in a browser, or use the VS Code Live Server extension to preview the site.

## Customize

- Update the bio, project descriptions, and links in `index.html`.
- Replace `assets/Urooj_Ahmed_Resume_Tech.pdf` with your latest resume PDF. The Resume links on the home page open this file.
- Adjust colors, typography, and layout in `styles.css`.

The site uses Google Fonts, which require an internet connection; it falls back to system fonts if they are unavailable.
